I saved the shorter version as `trimmed.md`. `instructions.md` is unchanged.

The original was already short (about 24 lines), so there wasn't much to cut. What I found:

- **Section headers:** the four headers (MISSION, INPUT, OUTPUT FORMAT, EXAMPLE OUTPUT) add structure that a prompt this short doesn't need. I replaced them with one opening paragraph followed by the list of rules.
- **Repetition:** the MISSION and INPUT sections said the same thing ("you'll get a topic, output must be consistent"). I merged them into one sentence, and "super consistent" became "keep the output format identical every time."
- **Typo:** "Concept Description **of** Definition" should have been "or Definition." This is fixed.
- **Bullet format:** "labeled list" bullet point format was vague. I replaced it with the literal pattern `- Label: explanation`, which is clearer than the description.
- **Wording:** "with word economy" became "concise," and "Two to Four Words Max" became plain prose.
- **Kept on purpose:**
  - "Exactly five" bullets, since that's a hard rule.
  - The full Speed Chess example, which pins down the format better than any rule could. I didn't cut it down, because a model will copy the example's length and tone.

The result has the same rules with about a third fewer words outside the example.
